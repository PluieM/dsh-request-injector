# 截图

README 引用的截图，把图片按下列文件名放进本目录即可自动显示；缺图时 GitHub 上会显示破图占位。

| 文件名 | 内容 |
| --- | --- |
| `plugin-config.png` | 插件配置页全貌（插件管理器 → 「请求头注入」行），含「基本」卡片与规则区 |
| `plugin-rule-card.png` | 规则卡片展开态，能看到匹配条件（provider / model / host）与请求头行 |
| `plugin-variables.png` | 配置页底部的「可用变量」速查表 |

建议在深色与浅色主题下各截一次时选其一，宽度 1200px 左右，可读性最好。
